# Cursor IDE Setup Notes

## PlatformIO IntelliSense Fix

**Affected versions:**
- Cursor `2.6.x` (tested on `2.6.19`, arm64)
- `davidgomes.platformio-ide-cursor` `0.0.1`
- `anysphere.cpptools` `2.0.x`

### Problem

The PlatformIO extension for Cursor (`davidgomes.platformio-ide-cursor`) crashes
silently on startup. It looks up its own metadata using the VS Code extension ID
`platformio.platformio-ide`, but in Cursor the actual ID is
`DavidGomes.platformio-ide-cursor`. The lookup returns `undefined`, throws
immediately, and the extension never finishes initializing.

Symptoms:
- PlatformIO sidebar stuck on "Initializing PlatformIO Core…"
- `anysphere.cpptools` reports `intelliSenseEngine is disabled`
- No IntelliSense for `Arduino.h`, AVR registers, library headers

### Fix

Patch one string in the extension's built JavaScript file:

```bash
sed -i '' \
  's/platformio\.platformio-ide/DavidGomes.platformio-ide-cursor/g' \
  ~/.cursor/extensions/davidgomes.platformio-ide-cursor-0.0.1-universal/dist/extension.js
```

Then reload the window: `Cmd+Shift+P` → **Reload Window**.

**Note:** the patch is overwritten if the extension updates. Re-apply after each update.

### IntelliSense setup (clangd)

IntelliSense is driven by clangd (`llvm-vs-code-extensions.vscode-clangd`), not the
Microsoft engine. clangd reads two files:

- `.clangd` — strips GCC-only flags (`-free`, `-fipa-pta`, `-mlongcalls`, …) that
  the clang frontend does not understand. This is clangd's native mechanism; no
  post-processing scripts are needed.
- `compile_commands.json` — generated by PlatformIO.

`.vscode/settings.json` passes `--query-driver=**/.platformio/packages/**` so clangd
queries the real cross-compiler (xtensa-lx106 / avr) for its system headers and
target triple. Without it, clangd falls back to the host (Apple) SDK and the whole
firmware lights up red (`sys/config.h not found`, wrong target).

Regenerate the compilation database after adding libraries or changing
`platformio.ini`. `pio` overwrites the file per run, so generate it for the env you
are editing:

```bash
# editing ESP-12F sources
pio run -e esp12f -t compiledb

# editing the AVR firmware
pio run -e pro16MHzatmega328 -t compiledb
```

Then `Cmd+Shift+P` → **clangd: Restart language server**.

`compile_commands.json` is in `.gitignore` — regenerate locally after cloning or when
changing dependencies.
